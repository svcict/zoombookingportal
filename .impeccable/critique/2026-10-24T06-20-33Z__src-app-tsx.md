### Priority Issues
1. [P0] Edit reports success when the save failed: handleSaveConfig ignores !res.ok, closes the modal and the parent toasts "synced"; the dashboard Edit path does the same. Fix: keep the modal open with an inline error, no success toast. Command: harden.
2. [P1] Edit modal shows invented features: "More Options" claims Teams Interop, Live Transcription (English, Tagalog, Spanish) and Watermark "configured for this tenant"; My Notes, Continuous Chat, PMI, Calendar map to no API field; hard-coded "ID: 869-563-2911" fallback; NEW badges. Fix: rebuild Edit around the intake's real fields + invitees + Host Key. Command: distill.
3. [P1] Edit modal isn't an accessible dialog: no role, Esc, focus trap or portal; unlabeled controls; faint placeholder; Save below the fold on phones. Fix: reuse the cancel-dialog pattern, sticky Cancel/Save footer. Command: harden.
4. [P2] Intake is settings-first: flat verbose settings (stay visible), "Agenda" pill and "Zoom Verified / AES-256" badge, read-only Name/Email in legacy grey fields. Fix: one "Booking as …" line, grouped compact settings with one-line help, drop badge and pill. Commands: layout, clarify.
5. [P2] Ambiguous buttons: popover NEXT vs outer Next, APPLY silently leaves the step; confirmation footer has 5 buttons with a duplicated Copy Invitation and two blue primaries. Fix: "Set end time" / "Done" / "Continue to details"; one primary per state. Command: clarify.
6. [P3] Tab from the popover's last button escapes to the page while it stays open; custom switches lack a visible focus ring; native email tooltip instead of inline error. Command: polish.
